# Be Aware n' Be Around

Static React PWA for the Epilepsy Foundation of Hong Kong's seizure first-aid guidance.

## Development

Requires Node.js 22 or later and npm.

```bash
npm install
npm run dev
```

## Verification

```bash
make test
make lint
make build
make e2e-test-full
```

`npm run build` writes deployable static assets to `dist/`. The PWA service worker and manifest are generated by Vite.

## Translations

Lingui catalogs are stored in `src/i18n/locales/`. After changing user-visible copy, update catalogs and translations before testing:

```bash
npm run i18n:extract
# Translate changed entries.
npm run i18n:compile
make test
```

`make test` runs `i18n:check` first. It detects extracted-catalog drift, restores the PO files it checks, and fails with this workflow so the worktree remains clean.

Education mode depends on the device's installed speech voices. Toy-mode recordings require microphone permission, are stored only in memory, and are discarded on refresh. The global click count is a device-local demonstration count, stored in browser local storage.

Visual baselines are kept under `tests/visual/baselines/`; update them only after a human-approved visual change.
